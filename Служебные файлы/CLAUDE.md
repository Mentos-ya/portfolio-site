- **Копия для России — Яндекс Облако:** https://iakupov.website.yandexcloud.net (бакет `iakupov`, облако `mentosprojects`, заведена 30.09.2026 — Vercel из России открывается не у всех). Обновляется сама: после `git push` хук `.claude/hooks/yandex-sync.py` в фоне запускает `scripts/deploy-yandex.sh` (журнал `.claude/yandex-sync.log`); проверка — `python3 scripts/check-site.py yandex` (статическая сборка с `STATIC_EXPORT=1` в `out/` и заливка по файлу с типом). Обычная сборка для Vercel от этого не меняется.
- **Выкладка = push в `main`, и делается сразу.** Илья 11.09.2026 разрешил выкладывать каждую правку на Vercel без отдельного «да»: сделал → собрал и проверил локально → push в `main` → проверил боевой сайт на ширине 1280 и 390. Спрашивать не нужно; спросить, только если правка удаляет данные или страницы, трогает Метрику или выносит на публичный сайт что-то новое про работу в Сбере.
- **Не отправлять на GitHub** (репозиторий открытый): `PRD.md` — там планы поиска работы, `handoff/`, временные `_variants*.html`. Все они закрыты в `.gitignore` — не добавлять их через `git add -f`.
- **Проверка перед «готово»:** `npm run build`, потом `npx next start -p <свободный порт>` и скриншоты на 1280 и 390; страница не должна быть шире экрана, в консоли не должно быть ошибок. Перед запуском убедиться, что порт не занят сервером соседнего проекта.

- **Оформление:** тема «Печать» — кремовая бумага, тёмно-синие чернила, электрический синий. За всей страницей неподвижный пиксельный растр `src/components/DitherBackground.tsx` (тянется к курсору), контент лежит на кремовых листах `.sheet` без рамки, с размытыми краями; у букв на листах кремовый «ореол» (`text-shadow`), чтобы текст читался поверх пикселей. Яркость растра зажата в шейдере — сплошных синих пятен нет. Шрифт — JetBrains Mono через `next/font` в `src/app/layout.tsx`, весь жирный: подключены только 700 и 800, а классы `font-*` в `tailwind.config.js` сдвинуты вверх (обычный = 700, выделенный = 800). Цвета — в `tailwind.config.js` (`paper`, `ink`, `electric`), общие классы — в `src/app/globals.css` (`sheet`, `card-glow`, `btn`, `section-title`, `path`). Класс `text-gradient-hero` теперь просто синий акцент. На первом экране общей подложки нет (`sheet-split`): у текста, фото и «Моего пути» свои размытые ореолы (`halo`, у фото — `halo-round`).
- **Кнопки и выноски — стиль «командная строка»** (выбран 11.09.2026): всё квадратное. `.btn-primary` — «> текст» на тёмно-синем, при наведении синеет и показывает блочный курсор; `.btn-secondary` — «[ текст ]» в рамке, при наведении цвета меняются местами; чипы — `.tag`, плашка статуса — `.cli-badge` («● Сейчас · …», без «$»), подсказки у ссылок — `.cli-tip` («> …»). Все блоки квадратные, без скруглений: карточки, превью и ролики, логотипы, картинки карусели, мягкие подложки листов. Круглыми остались только фото в кольце и точки «Моего пути».

Данные ИИ-проектов — `src/data/ai.json`.
